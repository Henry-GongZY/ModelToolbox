# PRD — 模型结构差异分析工作台 (ModelToolbox)

日期: 2026-10-28 · 状态: 活跃 · 作者: 自主 Agent（总控提示词驱动）

## 1. 一句话定位

本地优先的桌面级研发工具：像 Beyond Compare 一样**对比多个 ONNX 模型的计算图结构**，保留 Netron 式的算子级查看能力，并把板端逐层性能数据映射回计算图形成热力图。

## 2. 目标用户与场景

- 端侧/编译器工程师：模型改版前后结构审查（改了哪层、删了哪层、shape 怎么变）。
- 性能工程师：拿到板端逐层 profile，定位热点算子并对应到图节点。
- 训练工程师：检查导出的 ONNX 是否与预期结构一致（可选 PyTorch 模块树对照）。

## 3. MVP 边界（P0）

1. 导入单个 ONNX：元信息、输入/输出、计算图、节点详情（op/domain/attr/shape/dtype/参数形状）。
2. 双模型结构 diff：多阶段可解释匹配 → 差异分类；相同结构低干扰灰色，差异红色系 + 图标/文字（非仅颜色）。
3. 对齐布局（共享 match ID）、差异摘要与导航、同步平移缩放、搜索、仅看差异、节点详情、适合视图。
4. 匹配不确定/歧义必须显式标注低置信度，禁止仅凭名称或出现顺序强行匹配。
5. 自动化测试 + 可复现启动方法 + 诚实验收文档。

**非目标（本版）**：训练/推理执行、云端服务、多用户、权重数值逐 tensor 自动比对（仅作为显式独立模式的后备，不默认开启）、任意厂商私有 profile 格式。

## 4. P1

6. 数据结构不写死"两个模型"（内部多模型列表，UI 先做双模型并排）。
7. 公共连通子图折叠为摘要模块（节点数/边界 IO/覆盖模型数/置信度），可展开恢复，折叠状态可选同步。
8. 本地 PyTorch 项目 `nn.Module` 层级导入；leaf-module 规则；概览/详细切换；失败降级为模块树并说明。
9. 标准 JSON/CSV 逐层 profile 导入；节点耗时/占比/calls；独立热力图图层（可开关）。
10. diff 图层与热力图层独立开关，同开时可区分（边框/图标 vs 填充色）。

## 5. P2

11. 1k / 5k 节点合成 DAG 真实压测并报告。
12. diff/profile 导出 JSON/CSV + HTML/Markdown 报告。
13. 错误提示、加载态、取消/失败恢复、文档完善。

## 6. 关键验收原则

- 只承认"真实运行过并通过"的功能；测试禁止弱化断言凑绿。
- 每条 profile 测量记录可追溯为 已映射/未映射/歧义/组级，禁止静默丢弃。
- 形状未知 → unknown/null，不猜测；嵌套子图（If/Loop）不静默丢弃。
- 合成 fixture 必须标注为合成数据；性能数字必须写实测环境与结果。
