## 已知风险

- **torch 安装**：Python 3.9 只能装到支持 3.9 的 torch 版本；安装失败则 PyTorch 功能标记 BLOCKED，其余不受影响。（缓解：已在后台安装 CPU 版）
- **5k 节点 SVG 性能**：视口裁剪可能不够。（缓解：节流 + 批量渲染；实测后决定是否换 Canvas。）
- **Python 3.9 语法限制**：不用 match、`X | Y` 注解需 `from __future__ import annotations`。
- **双图对齐布局质量**：barycenter 启发式在密集交叉图上可能不完美，验收以"对应节点大体同行"为准并在报告如实记录。
